# CareerTrack 💼

CareerTrack is a simple Job and Internship Application Tracker.

## 🚀 Features

- 📊 Dashboard for application statistics
- 💼 Track job and internship applications
- 🎤 Track interviews
- 🔎 Search applications
- 📋 View application status
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 📁 Project Structure

- `index.html` – Website structure
- `style.css` – Website design and layout
- `script.js` – Interactive functionality

## 💡 Purpose

CareerTrack helps students and job seekers organize their job and internship applications in one place.
